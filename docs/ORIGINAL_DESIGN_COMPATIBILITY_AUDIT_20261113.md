**Verdict: NOT FULLY COMPATIBLE. Release blocked.** Green CI checks source contracts; it does not prove all original 1.4.1 gameplay paths or multi-bank coordination.

## Reference requirements and workload

The primary contracts are `AGENTS.md`, `docs/LOGISTICS_DESIGN.md`, `docs/ARCHITECTURE_DECISIONS.md`, `docs/BASELINE_INGRESS_EGRESS_MATRIX.md` (E01–E11 and R01–R06), `docs/COMPATIBILITY_TEST_PLAN.md`, and the owner's originally supplied multi-bank diagram.

The required geometry is **many contiguous vertical Sorter columns, one Hopper or Transporter above each column**, across separate physical transport banks interconnected through Sorter→Collector→Receiver links. Each bank/region can have local Bulk Storage and controller authority, but the total installation must operate as one logical destination-aware storage system. An arbitrary per-component pipe budget cannot determine the storage-system limit. Preserve non-new-block original networks. A performance target must eventually be stated and measured on a scaled multi-bank workload including a 200k backlog, **not** inferred from per-tick operation limits or mock timing.

## Required integrated correction order

1. **Unify endpoint selection for Hopper and Transporter-fed Sorter columns**, with parity for all original storage types and physical Collector handoff; preserve original filters/redstone, stable owning ticket and native/ordinary custody fences. Add deterministic mock integration that follows *one ordinary item and one native MR item* across at least two separated banks without losing ownership.
2. **Build one authoritative logical bank-routing view** over linked Collector→Receiver paths and per-region Bulk controllers. A remote matching filter must have precedence over an earlier bank's overflow/wildcard; enforce bounded hop/visited-cycle safety, stable route witnesses, no graph partition inflation, verified capacity, and HOLD when any higher-priority destination is unknown. Use existing unified writer and global intent; no new queue or scheduler.
3. **Restore original inactive/unloaded Receiver ingress behavior** with durable safe ownership for ordinary items and a lossless Collector-side MR wait/transfer mechanism. Cover redstone, restart, unregistered endpoints, and inventory saturation.
4. **Scale topology inspection** without unconditional 128-pipe topology rejection; protect tick time by incremental discovery, deterministic invalidation, and bounded work. Source tests should cover 1,400–2,000 Sorters across multiple Collector-connected banks and input backlogs, with exact conservation and staged fault injection.
5. **Implement the authenticated, repeatable, non-destructive archived-world Q4 cutover** from a verified restored copy, with immutable originals, legacy input isolation and pending opaque data HOLD. Keep 1.4.1-only worlds operational via equivalent routes.
6. **Complete runtime/link/menu/packaging parity**, prune only proven non-product artifacts, obtain exact-head CI, then conduct one integrated LAB product session and one archived-world migration/full acceptance session. Nothing authorizes production or automatic merging.
