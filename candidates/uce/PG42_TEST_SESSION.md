### Stopped-server state machine

1. **SOURCE PLAN:** Download the exact pinned UCE launcher. Run `-Mode Plan -ExpectedCommit <pin>` only (not launcher `Install` or `CheckLab` which expect a different predecessor). Then `python.exe candidates/uce/pg42_world_switch.py --mode plan --commit <pin>` and `python.exe candidates/uce/pg42_lab_patch.py --mode plan --commit <pin>`. These commands have **no server access**.
2. **WORLD PREFLIGHT / STAGE:** Gracefully stop LAB. `pg42_world_switch.py --mode check --commit <pin>` verifies exact current PG41 packs, preserved PG35 registries and LevelDB, no pre-existing PG42 folder or stage backup, and exact current server world name PG35. Then `--mode stage --commit <pin> --apply` creates a separate config/registration backup and changes **only** `level-name=HartUCECarrierLabPG42` atomically. Do not alter the real PG35 folder or a pack. No production access.
3. **GENERATE FRESH WORLD:** Start LAB BDS once. Verify its startup log says **Level Name: HartUCECarrierLabPG42**, not PG35. Stop LAB gracefully. Do not place test items or run Hart commands on this first launch.
4. **BIND / PROBE INSTALL:** With LAB stopped, run `pg42_world_switch.py --mode check-bind --commit <pin>` then `--mode bind --commit <pin> --apply`. This copies PG35's exact pack-registration bytes into the **new** world, never the LevelDB. Next run `pg42_lab_patch.py --mode check --commit <pin>` and then `--mode install --commit <pin> --apply`. The latter changes exactly **one file** (`scripts/main.js`) in the Hart behavior pack while preserving the PG40 FORENSIC HOLD and exact PG41 assets. Record the printed `lab-xxxxxxxxxxxx` backup tag; it is required for removal.
5. **TEST, FIRST START:** Start LAB. Confirm the server startup says PG42, not PG35. In game run `/hartlogistics:pg42_spawn` **exactly once**. The command reserves a one-time test record **in PG42 only** *before* spawn; if the spawn outcome is ambiguous it retains that record and refuses retries. It then checks nine slots and writes one new named/lore paper sample to slot 0. On success it prints `CREATED one carrier ID ...`. Run `/hartlogistics:pg42_audit`; capture `PASS persisted carrier ID ...`. If any HOLD appears, **do not rerun spawn or remove the entity**; stop and report logs.
6. **GRACEFUL RESTART / READ-ONLY AUDIT:** Stop and restart the same **PG42** world. Stand near the original spawn position (the carrier chunk must be loaded). Run `/hartlogistics:pg42_audit` again; capture the same ID, nine-slot/occupied=1 and intact name/lore. `audit` never creates entities or writes property/inventory. There is **no hard-crash durability proof** in this milestone.
7. **GUARDED CLEANUP BEFORE PG35 RETURN:** Gracefully stop LAB. Run `pg42_lab_patch.py --mode rollback --commit <pin> --backup-tag <captured lab tag> --apply` to **remove the temporary runtime probe and restore exact PG41 BP/RP**. Only after rollback, run `pg42_world_switch.py --mode restore --commit <pin> --apply` (refuses if the probe is still installed). The test world and both worlds' databases remain preserved; do not delete them by hand. The active server world is returned to the original PG35.
8. **PG35 READ-ONLY CONFIRMATION:** Start LAB only after cleanup. Confirm the log reads `HartUCEEmptyLabPG35`, and the original `/hartlogistics:status` still reports the PG40 FORENSIC HOLD and the original historical RESERVED owner. No cargo movement or recovery is authorized.
