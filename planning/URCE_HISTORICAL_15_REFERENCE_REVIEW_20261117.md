# URCE reference map — selectively learn from the older 1.5 skeleton

**Status:** source/documents examined on `main`, November 17, 2026. This is **design triage only**; it does not copy old source into 1.5, establish new native guarantees, revive Q5 or authorize a new build. The owner explicitly requested use of the past 1.5 skeleton **where it can be used**.

**Naming:** the selected architecture is **URCE** (Unified Routing and Custody Engine), rather than obsolete queue-centric Q5, or the typo “UCRE”.

## Rejected reference categories

- **Frozen historical unified-custody implementation** identified by [issue #79](https://github.com/partom24/HartLogistics2/issues/79) / [issue #82](https://github.com/partom24/HartLogistics2/issues/82): **DO NOT FETCH, COPY, CHERRY-PICK OR MERGE.** Retain only published failure/risk summaries.
- **Q5 runtime queues, key schemas, migration shims and dual-lane scheduling:** superseded by owner-selected URCE; historical q2/q3/q4 reads/recovery remain mandatory, but there is no prescribed Q5 intermediate.
- **Synthetic world snapshots, claimant-supplied ACKs, process-memory locks or active `reserveOrdinary` bookkeeping:** cannot be promoted to verified native inventory authority, persisted crash receipt or controller election.
- **Premature Bulk/Transporter gameplay integration:** URCE begins with planner, writer census and durable custody proof; avoid multiplying active writer paths before physical handoff can be reconciled.
- **Performance by lower polling frequency, reduced global budget or hidden per-tick chest caching:** violates native-first and original vanilla Hopper timing objectives.

## What is *actually* reusable next

1. **Responsibility vocabulary and interface candidates**, with new independent 1.4.2-anchored type/contract tests.
2. **Complete writer-census categories**, revalidated against every `setItem`, queue journal, world-prop and entity mutation in the active 1.4.2 source, rather than copied branch asserts.
3. **Negative fault scenarios**: unknown native chest capacity, missing/duplicate registry nodes, loaded/unloaded topology, stale epoch, external indistinguishable items, crash between physical write and journal clear.
4. **Owner design objectives and accepted bounded visual/Hopper observations**, preserved as compatibility checks with independent evidence labels.

**First planning artifact to complete next:** active 1.4.2 writer/effects census + pure local candidate-planner contract; only after baseline and custody gates should runtime writer adaptation be authorized. No changed 1.4.2 pack bytes, no automatic LAB operation, and no implicit production release.
