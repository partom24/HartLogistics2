# Python profile

Record supported Python versions, dependency/environment manager, lockfile policy, import/package entry point, automated tests, type/lint policy where useful, and packaging/distribution process. Keep credentials and machine-specific paths out of tracked source.

Unit tests and source lint are OFFLINE PASS; separate integration acceptance applies if APIs, databases, Discord, or other services are involved. A one-file utility shouldn't require an unnecessary server, Docker image or heavyweight release pipeline.
