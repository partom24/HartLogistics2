# Godot profile

Record engine and project format versions, enabled plugins, deterministic export presets, asset import assumptions, target OS/platform, and save-data schema. Validate scenes/resources/scripts in the appropriate engine and target export, rather than treating static checks as equivalent to runtime gameplay.

Safeguard user saves, input/config behavior, asset identifiers, and backwards compatibility where they exist. Headless/editor validation and actual exported-build acceptance are different evidence stages.
