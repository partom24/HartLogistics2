# Discord bot / integration profile

Record application registration/permission scopes, privileged intents when applicable, command deployment scope, token and secret handling, rate-limit behavior, retry/idempotency, and persistence boundaries. Tokens must never enter source, logs, screenshots, or template examples.

Mocked event handlers or local tests do not establish live bot behavior. Validate command registration, permission refusal and stateful recovery in an authorized test context when relevant; deployment and access changes require explicit owner approval. Python/JavaScript language checks belong to their own selected profiles.
