# Arma profile

For Arma missions, mods and dedicated servers: record Arma engine/version, mod dependencies and load order, mission/addon entry points, config parser validation, PBO/source provenance and (when used) signature/key compatibility. Check locality, multiplayer/JIP behavior and persistence when affected.

Use an existing authorized test/server workflow; no new server is mandated. Packaging and signed distribution are release-specific and should be evidence-backed, not assumed from a successful config parse.
